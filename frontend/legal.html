2. What this business does

openBatteryFlux is a free battery cell modelling tool. Nothing is sold on this site: there are no products, no paid plans, no subscriptions and no fees, so no price, delivery or cancellation terms apply. Accounts are free. Donations are voluntary and buy nothing — see the refunds and donations page.

6. Fonts, images and other assets

A plain answer to "are your fonts and images licensed?", because this project uses none that need a licence:

  • Fonts: the site loads no web fonts at all. It uses the operating system's own interface fonts (the system-ui stack). Nothing is requested from Google Fonts or any other font service, so there is no font licence to comply with and no visitor data sent to a font provider.
  • Images and illustrations: there are no photographs, no stock images, no icon fonts and no third-party icon packs. Every diagram, chart and icon is an inline SVG drawn inside the project's own files. The favicon is the same inline SVG as the logo.
  • Scripts and styles: no external script, stylesheet, iframe, pixel or tag is loaded. The only outside service the project uses is an email API on the server side (see the privacy notice, section 7), which runs off the visitor's browser entirely.
  • Spreadsheet and CSV sources used while building the library are listed in the project's repository. If any of them turns out to be under a licence incompatible with this use, tell us and the entry will be removed or the attribution added.

7. Accessibility statement

We aim to meet WCAG 2.2 level AA. What is in place today:

  • Semantic landmarks (nav, main) and one h1 per view with the sections below it, plus a "Skip to content" link that takes keyboard focus straight into the page.
  • Every page and figure is reachable and operable with a keyboard alone, with a visible focus outline; the theme toggle, menus and dialogs are real buttons and native dialog elements, so Escape closes them.
  • All 11 diagrams carry a descriptive accessible name in the page, and decorative drawings are hidden from assistive technology, so screen readers are not read a wall of path data.
  • Colour contrast of text and controls meets 4.5:1 (the light theme's accent colours were darkened for exactly this reason).
  • Animations respect the operating system's "reduce motion" setting, and nothing plays automatically, flashes, or runs on a timeout — there are no session time limits in the interface.
  • The tools have no drag-and-drop-only features: every file can also be chosen through a normal, keyboard-reachable file picker.

Known limitations, honestly: a few dense charts (confidence band, three-cell comparison) carry a lot of information, and their accessible name plus the text beside them cannot describe every point on the curve — tell us which chart you need and we will add a data table or a longer text description. The interface is available in English only. Measurement of the current implementation against every WCAG 2.2 criterion has not been done by an external auditor.

If anything here blocks you, write to the contact address with "accessibility" in the subject. We will answer, and we will tell you when a fix ships.
